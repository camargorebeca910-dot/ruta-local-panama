# Plataforma Web - Ruta Local Panamá

Proyecto final de INF 224, Metodología de Proyectos Informáticos. Universidad de Panamá, Facultad de Informática, Electrónica y Comunicación.

## Descripción

Sistema web para explorar destinos turísticos locales en Panamá, consultar fichas informativas, filtrar por categorías y regiones, visualizar recorridos en mapa y gestionar reservas de rutas turísticas para la agencia **Ruta Local Panamá**, sobre la base de datos `ruta_local_db` en PostgreSQL (9 tablas normalizadas).
